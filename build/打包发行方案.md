## 0. 一句话方案

保持现有技术栈（PySide6 GUI + PowerShell 脚本引擎）完全不动代码逻辑，只把
「发行形态」升级为：

- **GUI 用 PyInstaller onedir 打包**成带图标/版本属性的 `MAAFarmConsole.exe`（143 MB）
- **Inno Setup** 做向导式安装包（Setup.exe ≈ 52.6 MB）：
  安装向导/桌面+开始菜单快捷方式/卸载登记/中文界面，卸载时**保留全部用户数据**
- 兼发**便携目录版**（`build\layout`，可压 zip）
- 「检查更新」功能后续接 GitHub Releases（本文档不展开）

不采用：PyInstaller onefile（启动慢、杀软误报高）、MSIX/商店（容器虚拟化与
计划任务/进程控制不兼容，且审核过不了）、Electron/Tauri 重写（收益只有 UI，
真正值钱的 PowerShell 逻辑重写才是大坑）、MSI/WiX（成本高收益无）。

## 3. 架构与发行目录布局

```
发行目录（build\layout\，安装包/便携版共用）
├─ MAAFarmConsole.exe          双击启动（图标+版本属性）
├─ _internal\                  PyInstaller 运行时（app.ico 在此顶层）
├─ scripts\                    脚本引擎（master.ps1 等，排除 accounts/run_history）
├─ plugins\                    插件
├─ config.example.json
├─ 启动挂机.bat                 （探测内置 pwsh 优先）
└─ _setup\install_core.ps1     Inno [Run] 调用的收尾脚本
   └─ ps1_check.ps1
```

**为什么不需要改 GUI 代码的路径逻辑**：GUI 全部用 `__file__` 相对定位
（`Path(__file__).resolve().parents[N]`）。PyInstaller onedir 下模块
`__file__` 是 `<App>\_internal\<相对路径>`，层级深度与源码 `gui\...` 完全一致
——`parents[1]` 仍指向程序根，config.json / scripts / plugins / app.ico 的
定位语义不变。试做实测一致。

**运行时 Python 仍需随包**：插件、vision.py、导出、通知都是用真实解释器
跑 `.py` 的，冻结 exe 只解决界面本身；正式发行时安装包带 GUI 代码补丁
（见 §4.1）+ 由 CI 构建（CI 会先把 requirements 装进系统 python，
`gui\runtime` 由底层 Python 复制而来，PySide6/opencv/onnxruntime 就都在）。
本地试做里没有内置 runtime，插件相关功能在真机验证时补。

## 4. 试做发现并修复的坑（正式实施必须全部带上）

### 4.1 `sys.executable` 两处必炸点（GUI 代码改动）
`gui\core\export_runner.py`（导出）与 `gui\core\notify.py`（发通知）原来用
`sys.executable` 执行项目 `.py` 脚本。打包后 `sys.executable` 是界面 exe
本身，等于「重新拉起界面」而不是干活。

修法：`gui\core\util.py` 新增（同时补 `import sys`）：

```python
def python_exe_for_scripts():
    r"""跑项目内 Python 脚本（插件/导出/通知/识别）用的解释器路径。

    打包成 exe 后 sys.executable 是界面程序本体，不能再拿去执行 .py
    （会把脚本路径当参数重新拉起界面）。解析顺序：
    config.json paths.python 覆盖 → 源码运行用当前解释器（venv/系统）→
    打包运行依次找 gui\runtime、gui\.venv → 兜底 sys.executable（同旧行为）。
    """
    try:
        import config as appconfig
        p = str(((appconfig.load().get("paths") or {}).get("python")) or "").strip()
        if p and os.path.isfile(p):
            return p
    except Exception:
        pass
    if not getattr(sys, "frozen", False):
        return sys.executable
    root = Path(__file__).resolve().parents[2]
    for rel in (r"gui\runtime\python.exe", r"gui\.venv\Scripts\python.exe"):
        cand = str(root / rel)
        if os.path.isfile(cand):
            return cand
    return sys.executable
```

两个文件改为 `from core.util import ..., python_exe_for_scripts` 并把
`sys.executable` 换成 `python_exe_for_scripts()`（各自 `import sys` 可删，
两文件里没有别的用途）。配套测试：`tests\test_python_exe.py`（4 用例，
已在试做中编写并随全量测试通过；文件全文随本文档删除前已验证，直接复制采用）。

### 4.2 PS7 下 PSCustomObject 直接赋值不存在的键会抛异常（原安装器的雷）
`$cfg.paths.script_dir = ...` 这种写法在 PS5.1 会自动补键，在 **PS7 抛
「在此对象上找不到属性 script_dir」**——原 install.ps1 此处静默失败
（catch 吞掉），等于原安装器的路径检测半失效。统一改为：
`$cfg.paths | Add-Member -Force -NotePropertyName script_dir -NotePropertyValue ...`
（已有键覆盖、缺键新增；见 §6.5 全文，两处 script_dir/log_file 已改）。

### 4.3 路径替换必须幂等（升级/重装防改坏）
替换 `D:\1` → 目标路径时，若目标路径以 `D:\1` 开头（示例：默认装回 `D:\1`、
或装到 `D:\1AAA`），重跑会把已替换的内容再套一层。加保护（§6.5 已含）：

```powershell
# 幂等保护：已含目标路径的文件视为改写过（升级/重装场景），跳过替换
if ($c.Contains($defaultTarget) -and -not $c.Contains($Target)) { ...replace... }
```

### 4.4 5.1 语法误报：\"PS7 语法不许 5.1 当裁判\"
项目脚本全是 PS7 语法，安装收尾可能运行在于 5.1（powershell.exe），
5.1 的 Parser 对 `??`/三元等语法误报 → 中止安装。三段式（§6.5 已含）：
1. 本身运行在 PS7 → 直接 Parser 校验；
2. 5.1 但机器有 pwsh（按 内置便携 → `{pf}\PowerShell\7` → WindowsApps 顺序找）
   → 用 pwsh 跑子脚本 `ps1_check.ps1`（输出坏文件路径 + exit 1）；
3. 都没有 → 跳过并提示（项目脚本本来也跑不起来）。

### 4.5 Inno [Run] 解释器选择（InstallShell）
`[Run]` 用 `{code:InstallShell}` 动态选：内置便携 pwsh → 系统 pwsh →
WindowsApps 别名 → 兜底 `powershell.exe`(5.1)（§6.7 已含 [Code] 段）。

### 4.6 heso 语法细节
`[UninstallDelete]` 的类型值是 `filesandordirs`（不是 filesandirs）；含中文的
`.iss`/`.ps1` 必须存为 **UTF-8 带 BOM**（PowerShell 5.1 与 Inno 都依赖 BOM 认对编码）。

### 4.7 便携 pwsh 内置
`build\tools` 有 `PowerShell-*-win-x64.zip` 时随包内置（安装时解压到
`gui\runtime\pwsh`），并同步把两个 `启动挂机.bat` 的 pwsh 探测改为
**内置优先**（`%~dp0gui\runtime\pwsh\pwsh.exe` → Program Files → WindowsApps → where）。
CI 构建（现有 release.yml 流程）会自动下载内置；本地没有就仅提示、回退系统安装。

### 4.8 血的教训（2026-10-18 实际发生）：安装/卸载绝不动用户的计划任务
试做里卸载验证用了「按任务名强制删除」：
`schtasks /Delete /TN "MAA_明日方舟自动挂机" /F`（收菜任务同理）。这些名字
就是**用户本机真实在用的计划任务名**（GUI 班次/收菜页创建的），于是在沙盒里
跑一次安装→卸载试验，就把消费者电脑上两个真实任务删掉了——10-18 凌晨班次
因此没跑。教训固化成规则（§6.5/§6.7 已同步改掉）：
- 安装器**不创建、不修改、不删除任何计划任务**；任务生命周期永远归
  控制台 GUI「班次计划 / 收菜计划」页（`gui\core\scheduler.py`）管；
- 将来若确要在安装阶段建任务，必须写标记文件（如 `_setup\tasks-created.json`），
  卸载仅在标记存在时才删，且删前核对任务动作里含本安装目录。

### 6.1 build\pyinstaller\MAAFarmConsole.spec

```python
# -*- mode: python ; coding: utf-8 -*-
# MAA 挂机控制台 GUI 打包（PyInstaller onedir：启动快、杀软误报率低于 onefile）。
# 产物布局（与 GUI 代码的 __file__ 相对定位完全兼容，无需改代码）：
#   build\dist\MAAFarmConsole\
#     MAAFarmConsole.exe      <- 双击启动（_internal 里的 app.ico 提供图标）
#     _internal\              <- PyInstaller 运行时；frozen 下各模块 __file__ 指到这里，
#                                与源码 gui\xxx 的相对层级一致（parents[1]/[2] 语义不变）
# scripts / plugins / config.example.json 由 build\build_package.ps1 摆到同级。
import os

from PyInstaller.utils.hooks import collect_data_files

SPEC_DIR = SPECPATH                     # ...\build\pyinstaller
ROOT = os.path.dirname(os.path.dirname(SPEC_DIR))   # 项目根
GUI = os.path.join(ROOT, "gui")

a = Analysis(
    [os.path.join(GUI, "main.py")],
    pathex=[GUI],
    binaries=[],
    datas=[
        # 界面图标：frozen 下 main.py 按 dirname(__file__)\app.ico 找 → _internal 根
        (os.path.join(GUI, "app.ico"), "."),
    ] + collect_data_files("qfluentwidgets") + collect_data_files("qframelesswindow"),
    hiddenimports=[],
    hookspath=[],
    hooksconfig={},
    runtime_hooks=[],
    excludes=[],
    noarchive=False,
)

pyz = PYZ(a.pure)

exe = EXE(
    pyz,
    a.scripts,
    [],
    exclude_binaries=True,
    name="MAAFarmConsole",
    debug=False,
    bootloader_ignore_signals=False,
    strip=False,
    upx=False,
    console=True,   # 试产版保留控制台便于排错；转正式发行时改 False
    icon=os.path.join(GUI, "app.ico"),
    version=os.path.join(SPEC_DIR, "version_info.gen.txt"),
)

coll = COLLECT(
    exe,
    a.binaries,
    a.datas,
    strip=False,
    upx=False,
    upx_exclude=[],
    name="MAAFarmConsole",
)
```

### 6.3 build\pyinstaller\build_gui.ps1

```powershell
# 用 gui\.venv 里的 PyInstaller 打包 GUI（onedir）。
# 产物：build\dist\MAAFarmConsole\MAAFarmConsole.exe（含图标与版本属性）
# 只写 build\dist、build\pyi-work 与本目录的 version_info.gen.txt，不碰源码。
param(
    [string]$RepoRoot = "",
    [string]$Version = ""
)
$ErrorActionPreference = "Stop"
$ProgressPreference = "SilentlyContinue"

function Write-Step($m) { Write-Host "[打包] $m" -ForegroundColor Cyan }
function Write-Ok($m)   { Write-Host "[完成] $m" -ForegroundColor Green }

if (-not $RepoRoot) {
    # build\pyinstaller → 上两级 = 项目根
    $RepoRoot = Split-Path -Parent (Split-Path -Parent $PSScriptRoot)
}
$RepoRoot = [System.IO.Path]::GetFullPath($RepoRoot)
$pyi = Join-Path $RepoRoot "gui\.venv\Scripts\pyinstaller.exe"
if (-not (Test-Path $pyi)) {
    throw "未找到 PyInstaller：$pyi（先在 gui\.venv 里执行 python -m pip install pyinstaller）"
}

# ---------- 版本 ----------
if (-not $Version) {
    $tag = git -C $RepoRoot describe --tags --abbrev=0 2>$null
    if ($tag) { $Version = $tag.Trim() -replace '^v', '' }
}
if (-not $Version) { $Version = "0.0.0" }
$Version = $Version.Trim()
Write-Step "版本：$Version"

# 由模板生成 version_info.gen.txt（模板本身保持 @VERSION@ 占位符不被覆盖）
$verTpl = [System.IO.File]::ReadAllText(
    (Join-Path $PSScriptRoot "version_info.txt"), [System.Text.Encoding]::UTF8)
[System.IO.File]::WriteAllText(
    (Join-Path $PSScriptRoot "version_info.gen.txt"),
    $verTpl.Replace("@VERSION@", $Version),
    (New-Object System.Text.UTF8Encoding($false)))

Write-Step "PyInstaller onedir 打包（首次约几分钟）..."
& $pyi --clean --noconfirm `
    --distpath (Join-Path $RepoRoot "build\dist") `
    --workpath (Join-Path $RepoRoot "build\pyi-work") `
    (Join-Path $PSScriptRoot "MAAFarmConsole.spec") | Out-Null
if ($LASTEXITCODE -ne 0) { throw "PyInstaller 失败（exit=$LASTEXITCODE）" }

$exe = Join-Path $RepoRoot "build\dist\MAAFarmConsole\MAAFarmConsole.exe"
if (-not (Test-Path $exe)) { throw "未生成 $exe" }
Write-Ok $exe
```

### 6.4 build\build_package.ps1

```powershell
# 一键产线：打包 GUI → 组装发行目录 build\layout\ → 有 Inno Setup 就编译 Setup.exe。
# 产物：
#   build\layout\                 绿色便携目录（可直接压 zip 分发）
#   build\dist\MAA-Farm-Console-v<版本>-Setup.exe（装了 Inno Setup 时）
# 本脚本只写 build\ 下内容，不碰源码与任何真实用户数据。
param(
    [string]$RepoRoot = "",
    [string]$Version = "",
    [string]$ISCC = ""
)
$ErrorActionPreference = "Stop"
$ProgressPreference = "SilentlyContinue"

function Write-Step($m) { Write-Host "[产线] $m" -ForegroundColor Cyan }
function Write-Ok($m)   { Write-Host "[完成] $m" -ForegroundColor Green }
function Write-Warn($m) { Write-Host "[提示] $m" -ForegroundColor Yellow }

if (-not $RepoRoot) {
    $RepoRoot = Split-Path -Parent $PSScriptRoot   # build → 项目根
}
$RepoRoot = [System.IO.Path]::GetFullPath($RepoRoot)

# ---------- 1) 打包 GUI ----------
& (Join-Path $PSScriptRoot "pyinstaller\build_gui.ps1") -RepoRoot $RepoRoot -Version $Version

# ---------- 2) 组装发行目录 ----------
$layout = Join-Path $RepoRoot "build\layout"
if (Test-Path $layout) { Remove-Item $layout -Recurse -Force }
New-Item -ItemType Directory -Path $layout -Force | Out-Null
Write-Step "组装发行目录 build\layout ..."

# GUI exe（exe + _internal）
robocopy (Join-Path $RepoRoot "build\dist\MAAFarmConsole") $layout `
    /E /R:1 /W:1 /NFL /NDL /NJH /NJS /NP | Out-Null
if ($LASTEXITCODE -ge 8) { throw "复制 GUI 产物失败（robocopy exit=$LASTEXITCODE）" }

# 脚本引擎与插件（再排除一遍真实数据/生成物，防止误打包）
robocopy (Join-Path $RepoRoot "scripts") (Join-Path $layout "scripts") `
    /E /R:1 /W:1 /NFL /NDL /NJH /NJS /NP `
    /XD accounts run_history debug __pycache__ `
    /XF master_log.txt master.lock maa_done.signal master.log switch_output.tmp _shot.png | Out-Null
if ($LASTEXITCODE -ge 8) { throw "复制 scripts 失败（robocopy exit=$LASTEXITCODE）" }
robocopy (Join-Path $RepoRoot "plugins") (Join-Path $layout "plugins") `
    /E /R:1 /W:1 /NFL /NDL /NJH /NJS /NP `
    /XD plans __pycache__ /XF *.pyc | Out-Null
if ($LASTEXITCODE -ge 8) { throw "复制 plugins 失败（robocopy exit=$LASTEXITCODE）" }

foreach ($t in @("config.example.json", "启动挂机.bat")) {
    Copy-Item (Join-Path $RepoRoot $t) (Join-Path $layout $t) -Force
}

# 安装收尾脚本（Inno [Run] 调用；Inno 自己负责快捷方式）
$setupDir = Join-Path $layout "_setup"
New-Item -ItemType Directory -Path $setupDir -Force | Out-Null
Copy-Item (Join-Path $RepoRoot "build\installer\install_core.ps1") `
    (Join-Path $setupDir "install_core.ps1") -Force
Copy-Item (Join-Path $RepoRoot "build\installer\ps1_check.ps1") `
    (Join-Path $setupDir "ps1_check.ps1") -Force

# 便携 pwsh（build\tools 有缓存 zip 就内置；安装时解压到 gui\runtime\pwsh）
$pwshZip = Get-ChildItem (Join-Path $RepoRoot "build\tools") `
    -Filter "PowerShell-*-win-x64.zip" -ErrorAction SilentlyContinue |
    Sort-Object Name -Descending | Select-Object -First 1
if ($pwshZip) {
    $rtDir = Join-Path $layout "gui\runtime"
    New-Item -ItemType Directory -Path $rtDir -Force | Out-Null
    Copy-Item $pwshZip.FullName (Join-Path $rtDir "pwsh.zip") -Force
    Write-Ok "便携 pwsh 已内置（$($pwshZip.Name)）"
} else {
```

### 6.5 build\installer\install_core.ps1

```powershell
# MAA Farm Console - install core script
# Prereq: MuMu emulator and MAA are already installed (this package does not install them).
# 由安装器（Inno Setup [Run]）以参数方式调用，无交互。职责与旧版 7zSFX 的
# install.ps1 一致：修正脚本硬编码路径、解压内置便携 pwsh、生成 config.json
# 并自动检测 MAA/MuMu 路径。快捷方式由安装器负责，这里不管；
# 计划任务一律不碰（归 GUI 管，见 §4.8）。
param(
    [Parameter(Mandatory = $true)][string]$Target,
    [string]$Version = "0.0.0"
)
$ErrorActionPreference = "Stop"

function Write-Step($m) { Write-Host "[安装] $m" -ForegroundColor Cyan }
function Write-Ok($m)   { Write-Host "[完成] $m" -ForegroundColor Green }
function Write-Warn($m) { Write-Host "[提示] $m" -ForegroundColor Yellow }

Write-Host "================================================"
Write-Host "  MAA 挂机控制台 v$Version 安装" -ForegroundColor Cyan
Write-Host "================================================"
$defaultTarget = "D:\1"   # 旧版脚本里硬编码的根路径（替换源头）

function Find-FileUnder($roots, $file, $depth = 4) {
    foreach ($r in $roots) {
        if (-not $r -or -not (Test-Path $r)) { continue }
        $hit = Get-ChildItem -Path $r -Recurse -Depth $depth -Filter $file -File `
            -ErrorAction SilentlyContinue | Select-Object -First 1
        if ($hit) { return $hit.FullName }
    }
    return $null
}

function Find-MaaExes {
    $roots = @(
        "D:\软件",
        "$env:ProgramFiles",
        "D:\Program Files",
        "$env:LOCALAPPDATA\Programs"
    )
    $dirs = @()
    foreach ($r in $roots) {
        if (Test-Path $r) {
            $dirs += @(Get-ChildItem -Path $r -Directory -Filter "MAA*" `
                -ErrorAction SilentlyContinue)
        }
    }
    $exes = @()
    foreach ($d in $dirs) {
        $exes += @(Get-ChildItem -Path $d.FullName -Recurse -Depth 3 -Filter "MAA.exe" `
            -File -ErrorAction SilentlyContinue | Select-Object -ExpandProperty FullName)
    }
    # 按所在目录名的版本号降序（取 First 即最新版）：纯字符串排序会把
    # MAA-v6.11 排在 MAA-v6.9 前，多版本并存时挑到旧版；版本段解析不了
    # （目录名不带版本号，如手动改名的 B服 目录）按 0.0 排到末尾不挡道
    return @($exes | Sort-Object -Unique -Property {
            $name = Split-Path -Leaf (Split-Path -Parent $_)
            if ($name -match '^MAA-v(\d+(?:\.\d+)*)') {
                try { [version]$Matches[1] } catch { [version]'0.0' }
            } else { [version]'0.0' }
        } -Descending)
}

Write-Step "安装目录：$Target"

# 1) 修正脚本中的硬编码路径（安装到非默认目录时）
# 目标路径会被逐字写进脚本内容（替换默认路径字样）。含引号/美元符/括号等
# 字符时会改坏代码（字符串提前闭合、被当表达式解析），先拒绝并说明。
if ($Target -ne $defaultTarget) {
    if ([regex]::IsMatch($Target, '[\"''`$;(){}%!<>*?]') -or
        $Target -match '[.\s]$' -or $Target -match '^[A-Za-z]:$') {
        throw "安装目录含有无法安全改写脚本的特殊字符（引号/美元符/括号/结尾空格或点等），中止安装。"
    }
    Write-Step "修正脚本中的硬编码路径..."
    Get-ChildItem $Target -Recurse -File -ErrorAction SilentlyContinue |
        Where-Object {
            $_.Extension -in ".py", ".ps1", ".bat" -and
            $_.FullName -notmatch '\\gui\\(runtime|\.venv|_internal)\\|\\_setup\\'
        } |
        ForEach-Object {
            try {
                $c = [System.IO.File]::ReadAllText($_.FullName)
                # 幂等保护：已含目标路径的文件视为改写过（升级/重装场景），
                # 跳过替换，防止 "D:\1" 作为目标路径前缀时被二次替换改坏
                if ($c.Contains($defaultTarget) -and -not $c.Contains($Target)) {
                    [System.IO.File]::WriteAllText($_.FullName, $c.Replace($defaultTarget, $Target))
                    Write-Ok ("已修正：" + $_.FullName)
                }
            } catch {}
        }

    # 替换后语法自检：万一替换撞上代码里的字符串/正则上下文把文件改坏，
    # 在这里拦下并中止安装，别等用户运行时才炸
    Write-Step "校验改写后的脚本语法..."
    $bad = @()
    $py = Join-Path $Target "gui\runtime\python.exe"
    if (-not (Test-Path $py)) { $py = Join-Path $Target "gui\.venv\Scripts\python.exe" }
    if (Test-Path $py) {
        Get-ChildItem $Target -Recurse -File -Filter *.py -ErrorAction SilentlyContinue |
            Where-Object { $_.FullName -notmatch '\\gui\\(runtime|\.venv|_internal)\\|\\_setup\\' } |
            ForEach-Object {
                & $py -m py_compile $_.FullName 2>$null
                if ($LASTEXITCODE -ne 0) { $bad += $_.FullName }
            }
    } else {
        Write-Warn "未找到内置 Python，跳过 .py 语法校验（仅校验 .ps1）"
    }
    # .ps1 语法检查：注意引擎版本——本脚本可能运行在 PowerShell 5.1
    # （powershell.exe）下，而项目脚本要求 PS7 语法，5.1 的 Parser 会误报
    # ?? / 三元等语法并中止安装。5.1 下改为：有 pwsh 7 就用它跑子校验脚本
    # （ps1_check.ps1，输出坏文件路径 + exit 1），没有 pwsh 就跳过并提示。
    $isPs7 = $PSVersionTable.PSVersion.Major -ge 7
    if ($isPs7) {
        Get-ChildItem $Target -Recurse -File -Filter *.ps1 -ErrorAction SilentlyContinue |
            Where-Object { $_.FullName -notmatch '\\gui\\(runtime|\.venv|_internal)\\|\\_setup\\' } |
            ForEach-Object {
                $errs = $null
                $null = [System.Management.Automation.Language.Parser]::ParseFile(
                    $_.FullName, [ref]$null, [ref]$errs)
                if ($errs) { $bad += $_.FullName }
            }
    } else {
        $pwsh7 = @(
            (Join-Path $Target "gui\runtime\pwsh\pwsh.exe"),
            "$env:ProgramFiles\PowerShell\7\pwsh.exe",
            "$env:LOCALAPPDATA\Microsoft\WindowsApps\pwsh.exe"
        ) | Where-Object { Test-Path $_ } | Select-Object -First 1
        if ($pwsh7) {
            Write-Step "用 PowerShell 7 子进程校验 .ps1 语法..."
            $checkOut = & $pwsh7 -NoProfile -ExecutionPolicy Bypass `
                -File (Join-Path $Target "_setup\ps1_check.ps1") -Target $Target 2>&1
            if ($LASTEXITCODE -ne 0) { $bad += @($checkOut) }
        } else {
            Write-Warn "未找到 PowerShell 7，跳过 .ps1 语法校验（项目脚本需 PS7 才能运行）"
        }
    }
    if ($bad) {
        Write-Warn "以下文件改写后语法校验失败（请截图反馈）："
        $bad | ForEach-Object { Write-Warn ("  " + $_) }
        throw "脚本语法校验失败，已中止安装。请换安装目录后重试。"
    }
    Write-Ok "脚本语法校验通过"
}

# 2) 便携版 PowerShell 7：安装包内置 gui\runtime\pwsh.zip 时解压备用
#    （计划任务 / GUI / master 后台子进程都优先用它，目标机器无需安装 PowerShell 7）
$pwsZip = Join-Path $Target "gui\runtime\pwsh.zip"
$pwsDir = Join-Path $Target "gui\runtime\pwsh"
if ((Test-Path $pwsZip) -and -not (Test-Path (Join-Path $pwsDir "pwsh.exe"))) {
    Write-Step "解压内置便携版 PowerShell 7..."
    try {
        Expand-Archive -Path $pwsZip -DestinationPath $pwsDir -Force
        Remove-Item $pwsZip -Force -ErrorAction SilentlyContinue
        Write-Ok "便携版 PowerShell 7 就绪（gui\runtime\pwsh）"
    } catch {
        Write-Warn "便携版 PowerShell 解压失败：$($_.Exception.Message)"
        Write-Warn "将回退使用系统安装的 PowerShell 7（如有）"
    }
}

# 3) config.json generation + path auto-detection
$cfgPath = Join-Path $Target "config.json"
if (-not (Test-Path $cfgPath)) {
    Write-Step "生成 config.json 并自动检测 MAA/MuMu 路径..."
    Copy-Item (Join-Path $Target "config.example.json") $cfgPath -Force
    $mumuRoots = @(
        "D:\软件\MuMu模拟器",
        "C:\Program Files\Netease\MuMuPlayer-12.0",
        "C:\Program Files\Netease",
        "D:\Program Files\Netease\MuMuPlayer-12.0",
        "D:\Program Files\Netease",
        "$env:ProgramFiles\Netease",
        "$env:LOCALAPPDATA\Netease"
    )
    $adb = Find-FileUnder $mumuRoots "adb.exe" 5
    $cli = Find-FileUnder $mumuRoots "mumu-cli.exe" 5
    if (-not $cli) { $cli = Find-FileUnder $mumuRoots "MuMuManager.exe" 5 }
    $maaExes = Find-MaaExes
    $maaOfficial = $maaExes |
        Where-Object { $_ -notmatch '[（(]b[）)]|Bilibili' } |
        Select-Object -First 1
    if (-not $maaOfficial) { $maaOfficial = $maaExes | Select-Object -First 1 }
    $maaBili = $maaExes |
        Where-Object { $_ -ne $maaOfficial -and ($_ -match '[（(]b[）)]|Bilibili') } |
        Select-Object -First 1
    if (-not $maaBili) {
        $maaBili = $maaExes | Where-Object { $_ -ne $maaOfficial } | Select-Object -First 1
    }
    try {
        $cfg = [System.IO.File]::ReadAllText($cfgPath, [System.Text.Encoding]::UTF8) | ConvertFrom-Json
        # PS7 上对 PSCustomObject 直接给不存在的键赋值会抛异常（PS5.1 会补键），
        # 统一用 Add-Member -Force：键在则覆盖、键缺则新增
        $cfg.paths | Add-Member -Force -NotePropertyName script_dir `
            -NotePropertyValue (Join-Path $Target "scripts")
        $cfg.paths | Add-Member -Force -NotePropertyName log_file `
            -NotePropertyValue (Join-Path $Target "scripts\master_log.txt")
        if ($adb) { $cfg.paths.adb = $adb; Write-Ok ("检测到 ADB：" + $adb) }
        else { Write-Warn "未检测到 MuMu ADB，请稍后在「运行设置」页填写" }
        if ($cli) { $cfg.paths.cli = $cli; Write-Ok ("检测到 MuMu CLI：" + $cli) }
        if ($maaOfficial) {
            # 示例配置不预置官服 MAA 键（默认值自动探测，不钉死版本号），
            # PSCustomObject 对不存在的属性直接赋值会抛异常——用 Add-Member
            # -Force：键缺失则新增、已存在则覆盖
            $cfg.paths | Add-Member -Force -NotePropertyName maa_official `
                -NotePropertyValue $maaOfficial
            $cfg.paths | Add-Member -Force -NotePropertyName maa_official_dir `
                -NotePropertyValue (Split-Path -Parent $maaOfficial)
            Write-Ok ("检测到 MAA（官服）：" + $maaOfficial)
        } else { Write-Warn "未检测到官服 MAA，请稍后在「运行设置」页填写" }
        if ($maaBili) {
            $cfg.paths | Add-Member -Force -NotePropertyName maa_bilibili `
                -NotePropertyValue $maaBili
            $cfg.paths | Add-Member -Force -NotePropertyName maa_bilibili_dir `
                -NotePropertyValue (Split-Path -Parent $maaBili)
            Write-Ok ("检测到 MAA（B服）：" + $maaBili)
        }
        # Depth 100：accounts[].base_schedule.batches[].manufacture[].operators
        # 这类深层结构将来再加一层就会被 Depth 10 静默截断（丢配置不报错）
        $json = $cfg | ConvertTo-Json -Depth 100
        [System.IO.File]::WriteAllText($cfgPath, $json, (New-Object System.Text.UTF8Encoding($false)))
        Write-Ok "config.json 已生成"
    } catch {
        Write-Warn "config.json 自动配置失败：$($_.Exception.Message)"
    }
} else {
    Write-Ok "已存在 config.json，跳过配置生成（可打开「运行设置」修改）"
}
```

## 7. 正式实施步骤（建议顺序）

1. 按上表把文件落到仓库；`install_core.ps1`/`ps1_check.ps1`/`*.iss`/两个构建
   `.ps1` 统一存 **UTF-8 带 BOM**（`MAAFarmConsole.iss` 有中文必带 BOM）。
2. 在 `D:\1` 的 `gui\.venv` 里执行：`python -m pip install pyinstaller`。
3. 试门面（不动原数据）：
   `gui\.venv\Scripts\python.exe -m unittest discover -s tests`（全量 116 个，应全绿）
4. 产线：`pwsh build\build_package.ps1 -Version <x.y.z>
   -ISCC "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"`
   —— 本地没 Inno Setup 到 GitHub 推 tag 走 CI 也可。
5. 自检：`build\dist\MAAFarmConsole\MAAFarmConsole.exe --smoke`（QT 可 offscreen；
   **请先在 dist 目录放一个指向假路径的 config.json**，避免启动逻辑触到真实 MAA
   目录——试做就是这么测的）。
6. 安装/卸载验证（本机可做、可控、可回退）：
   `Setup.exe /CURRENTUSER /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
   /DIR="D:\临时目录" /NOICONS /TASKS="" /LOG="install.log"`
   → 验 config.json 生成 → 再 `unins000.exe /VERYSILENT` → 验 HKCU 登记清干净。
   （提示：句末不要带空格；目标目录别含引号/美元符/括号等特殊字符）
7. 真机强化（必须你本人做）：装到真实目录后跑一轮「立即运行」挂机全链路
   （涉及模拟器/MAA，不在脚本自动化验证范围）。
